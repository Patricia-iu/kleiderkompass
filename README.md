
# Kleiderkompass

Fiktives Studienprojekt zur Registrierung von Kleiderspenden.

## Starten

1. Projektordner in Visual Studio Code öffnen.
2. Die Erweiterung „Live Server“ installieren.
3. index.html mit „Open with Live Server“ starten.

Zum Laden von Bootstrap über jsDelivr ist eine Internetverbindung nötig.

## Funktionen

- Kleidungsart und Krisengebiet auswählen
- Persönliche Übergabe oder Abholung wählen
- Bei Abholung Pflichtfelder und Postleitzahl prüfen
- Registrierungsangaben auf einer Bestätigungsseite anzeigen

Die Abhol-PLZ muss fünfstellig sein und mit 10 beginnen.

## Speicherung

Die Angaben werden im Browser-Tab mit sessionStorage gespeichert.
Es gibt kein Backend und keine Übermittlung an einen Verein.
Bitte ausschließlich fiktive Testdaten verwenden.

## Technik

HTML, CSS, JavaScript und Bootstrap 5.3.8.
